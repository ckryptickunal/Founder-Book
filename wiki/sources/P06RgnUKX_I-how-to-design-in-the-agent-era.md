# How To Design In The Agent Era

## Summary

Steven Haney, founder of Paper, discusses the evolution of design tools in the era of AI agents. Paper is an agent-native design tool that uses HTML and CSS as its rendering engine, allowing for seamless integration with AI agents and improved design-to-developer handoff. The conversation covers the importance of maintaining human-led design, avoiding 'vibe-coded' AI design patterns, and the philosophy of building software that prioritizes quality and intentionality over feature bloat.

## Key Ideas

- Design tools should be agent-native by using standard web technologies (HTML/CSS) to reduce token spend and improve accuracy.
- The 'design-to-dev' handoff is solved by treating the code base as the single source of truth, allowing designers and agents to work on the same underlying code.
- AI-generated designs often suffer from 'vibe-coded' patterns (overuse of bold, excessive font sizes, purple gradients, and unnecessary widgets) that signal a lack of intentionality.
- Human-led design remains a critical differentiator for companies; AI should be used to accelerate the process, not replace the human decision-making and taste.
- Building a successful startup involves identifying bottlenecks, talking to users daily, and being values-aligned with the target market.
- The 'new agent stack' involves a combination of tools like Cursor, Claude Code, and Paper, where Paper serves as the visual interface for agentic workflows.

## Notable Claims

- Using HTML and CSS as a rendering engine makes design tools more efficient for AI agents. Evidence: Agents are trained on HTML/CSS, reducing the need for translation and lowering token usage.
- Exceptional design is a key differentiator for successful companies. Evidence: Historical analysis of top companies over the last 10-20 years shows a correlation between high-quality design and success.
- Designers should limit font sizes and weights to avoid the 'AI-generated' look. Evidence: Models tend to over-complicate designs; simplifying typography creates a more intentional and trustworthy aesthetic.
